# 工具站建设计划(Next.js 15 + Cloudflare Pages)

## 决策摘要(我用最佳判断替你定的,如不认可可改)

基于前面所有真实案例研究(eastondev、哥飞、Reddit),我替你做了三个决策:

1. **站点定位**:通用工具站(中英文,以英文流量为主赚高 RPM)
2. **首工具方向**:开发者工具类(纯前端实现、起步最快)
3. **首工具选题**:**Slug Generator**(URL slug 生成器)——实现极简,能最快验证整条链路

**为什么是 Slug Generator**:纯前端、零依赖、5 分钟实现、能立即跑通"工具→部署→SEO"全流程,是验证项目可行性的最佳 MVP。跑通后第二个工具再上更复杂的高 RPM 工具。

## 技术栈(全部免费,基于真实案例验证)

| 组件 | 选择 | 理由 |
|---|---|---|
| 框架 | **Next.js 15 App Router + TypeScript** | 静态导出(SEO 友好)、生态成熟 |
| 样式 | **Tailwind CSS** | 工具站快速搭 UI |
| 部署 | **Cloudflare Pages**(免费) | 带宽无限、自带 CDN/SSL |
| 分析 | Cloudflare Analytics + GSC(免费) | 零成本 |
| 配置 | `output: 'export'` 静态导出 | 利于 SEO、零服务器成本 |

## 核心实现要点

### 1. SEO 优化(整站核心)
- 每页独立 `<title>` / `meta description` / Open Graph
- 结构化数据(JSON-LD Schema.org WebApplication)
- 自动生成 sitemap.xml + robots.txt
- 语义化 HTML、面包屑导航
- 静态预渲染所有页面

### 2. Slug Generator 工具(首工具)
- 实时输入转换:标题 → URL slug
- 可选分隔符(- / _)、大小写、转音译、去特殊字符
- 复制到剪贴板
- 历史记录(localStorage)
- 配套 800 字教程(content.mdx,过 AdSense 审核的关键)

### 3. AdSense 审核就绪(不接广告,但预留)
- 完整的 4 个必备页面(隐私/关于/联系/服务条款)
- 工具页配套深度内容(规避"low value content"拒审)
- 广告位组件 `<AdSlot>` 预留位置,通过审核后填代码即可

### 4. 可扩展架构
- `lib/tools.ts` 集中管理工具元数据,加新工具只需:
  1. 在 `app/tools/` 新建目录
  2. 在 `lib/tools.ts` 加一条配置
  3. 首页和导航自动更新
- 未来加 invoice generator、calculator 等高 RPM 工具无成本

## 部署后你能拿到什么

- 一个可直接 `npm run dev` 本地预览的完整工具站
- 跑通后 `npm run build` → 生成 `out/` 静态文件 → 上传 Cloudflare Pages 即上线
- 架构支持你后续自己加工具,不用每次改我

## 不包含的范围(明确边界)

- ❌ 不接入 AdSense 代码(你说后面搞,我只预留广告位)
- ❌ 不做用户系统/数据库(纯静态,零成本)
- ❌ 不做后端 API(slug 生成纯前端)
- ❌ 不部署上线(只交付代码,部署步骤写 README)
