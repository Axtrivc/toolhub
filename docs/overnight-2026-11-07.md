# 工作台可靠性改进（2026-11-07）

本轮保留现有界面风格、静态导出和多语言，没有接入广告或部署。

- 随手记的格式化、Base64、大小写、清空操作可撤销一次；后续手动输入会清除旧撤销，避免覆盖新的输入。
- 浏览器存储失败时保留当前文本，并提示复制备份，不再显示已保存。
- 复制回退会检查实际返回值；失败提示手动复制，恢复原焦点。
- Base64 解码拒绝非法 UTF-8，避免静默插入替换字符；保留原文中的 BOM。
- 支持另一标签页清空存储后的同步；读取失败时不清空当前内存文本。

这些是纯函数、状态/组件处理器测试和现有工具计算冒烟，不等于浏览器视觉或真机测试。
